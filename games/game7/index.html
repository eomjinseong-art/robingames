끝말잇기!

컴퓨터와 끝말잇기 대결! 시작하기 전에 규칙을 읽어 보세요.

끝말잇기 규칙

  1. 앞 단어의 마지막 글자로 시작해요.

    사과 → 과자 → 자동차

  2. 두음법칙을 허용해요.

    끝 글자의 첫소리가 바뀔 수 있어요. ㄹ은 ㅣ·ㅑ·ㅕ·ㅛ·ㅠ·ㅒ·ㅖ 앞에서 ㅇ으로, 다른 모음 앞에서는 ㄴ으로 바뀌어요. ㄴ은 그 모음 앞에서 ㅇ으로 바뀌어요. 원래 글자로 시작해도 맞아요.

    • 력 → 역 (달력 → 역사)
    • 녀 → 여 (소녀 → 여자)
    • 료 → 요 (재료 → 요리)
    • 라 → 나 (카메라 → 나라)
    • 리 → 이 (다리 → 이야기)
    • 류 → 유 (종류 → 유리)
    • 로 → 노 (도로 → 노래)
  3. 두 글자 이상의 명사만 써요.

    표준국어 보통명사만 인정해요.

  4. 완성형 한글만 쓸 수 있어요.

    자음·모음만 있는 글자, 영어, 숫자, 특수문자, 띄어쓰기는 안 돼요.

  5. 이미 나온 단어는 다시 쓸 수 없어요.

    나와 컴퓨터가 말한 단어를 모두 기억해요.

  6. 제한 시간 안에 답하지 못하면 져요.

    내 차례는 12초예요. 컴퓨터가 단어를 소리 내어 말한 뒤에 시간이 시작되고, 음성을 끄면 바로 시작해요. 틀린 단어를 고쳐 넣는 동안에도 시간은 흘러요. 규칙을 보는 동안에는 시간이 멈춰요.

  7. 고유명사와 사투리는 안 돼요.

    사람 이름, 지명, 상표, 사투리는 쓰지 않아요.

  8. 한방단어는 끝 글자로 잇는 말이 거의 없는 단어예요.

    예를 들어 하늘은 ‘늘’로 시작하는 명사가 거의 없어, 내면 상대가 바로 질 수 있어요.

    기본은 금지예요. 허용으로 바꾸면 나만 한방단어를 쓸 수 있고, 컴퓨터는 첫 턴에도 그 다음에도 한방단어를 내지 않아요.
